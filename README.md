# Meyer G-SDK Manager — Güncelleme Kanalı

Bu repo, Meyer G-SDK Manager masaüstü uygulamasının otomatik güncelleme
yayınlarını barındırır. Her `vX.Y.Z` etiketi bir GitHub Release'dır:

- `Meyer G-SDK Manager Setup X.Y.Z.exe` — NSIS kurulumcusu
- `*.blockmap` — fark (delta) indirme verisi
- `latest.yml` — electron-updater manifesti
- `update.json` — zorunlu/opsiyonel bayrağı ve sürüm notu

Kaynak kod bu repoda tutulmaz.
